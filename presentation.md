# Demo: AI Crop Predictor

![bg left:30%](https://images.unsplash.com/photo-1574943320219-553eb213f72d?w=400)

**What it does:**
- Takes crop name + month as input
- Returns:
  - Expected demand level
  - Price trend
  - AI recommendation (Grow / Avoid)

**Real Impact:**
- Helps farmers decide BEFORE sowing
- Prevents market glut situations

---

# Tech Stack

| Component | Technology |
|:---|:---|
| Backend | [Node.js](https://nodejs.org/) + [Express](https://expressjs.com/) |
| Data | CSV with historical trends |
| Frontend | HTML + CSS + JavaScript |
| Hosting | Local or can be deployed on [Render](https://render.com/) |

---

# Demo Flow

```
1. Open http://localhost:3000
2. Select Crop: Tomato
3. Select Month: June
4. Click "Predict"
5. See: High Demand, Volatile Price, AVOID
```

---

# Live Demo Time!

**Let's run the application...**

1. Navigate to `/demo` folder
2. Run `npm install`
3. Run `node index.js`
4. Open browser → `localhost:3000`

🔗 **GitHub Repo:** [github.com/yashsm01/AI-for-Atmanirbhar-Bharat-HEI-Pre-Summit-Engagements-towards-IndiaAI-Impact-Summit-2026](https://github.com/yashsm01/AI-for-Atmanirbhar-Bharat-HEI-Pre-Summit-Engagements-towards-IndiaAI-Impact-Summit-2026)

---

# Understanding the Output

| Input | Output |
|:---|:---|
| Tomato + June | ⚠️ Avoid – Monsoon volatility |
| Wheat + November | ✅ Grow – Peak demand season |
| Onion + October | ✅ Grow – Low supply expected |

---

# Behind the Scenes

```javascript
// Simplified prediction logic
const result = database.find(
  item => item.crop === crop && item.month === month
);
return {
  demand: result.historical_demand,
  price: result.price_trend,
  recommendation: result.recommendation
};
```

*This can be enhanced with ML models*
